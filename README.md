# Middle-earth — launcher files

Файлы распространения для собственного лаунчера Minecraft **Middle-earth**.

## Целевая сборка

- Minecraft: **1.21.8**
- Mod loader: **Fabric**
- Fabric Loader: **0.20.1**
- Java: **25** (сервер уже проверен на этой версии)
- Игровой профиль: **Middle-earth**

## Структура

- `distribution.json` — конфигурация профиля для HeliosLauncher.
- Файлы сборки и моды — будут опубликованы отдельными версиями в **GitHub Releases**, а не добавлены в Git-историю репозитория.

## Важно

Сборка ещё подготавливается. Не скачивайте файлы из этого репозитория как готовый клиент, пока не опубликован первый релиз и не проверен запуск через лаунчер.
